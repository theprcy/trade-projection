# trade-projection

### Signal
Type in a stock ticker (like AAPL or TSLA) and this site tells you whether the current trend reads BUY or SELL, based on one simple rule:
 
if today's closing price is above the stock's 50-day average price -> BUY
if today's closing price is below the stock's 50-day average price -> SELL

**The idea:** when a stock is trading above where it's typically been over the last 50 days, that's read as upward momentum. Below that average reads as downward momentum.

Along with the signal, you'll see the current price, the 50-day average, and a chart showing how the two have moved over the past few month, so you can see the trend, not just the label.
