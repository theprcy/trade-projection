how this reads the market

Signal pulls the last 60 daily closes for the ticker you enter and averages the most recent 50. If the closing price sits above that average, the trend reads BUY. If it sits below, the trend reads SELL. This is a single, simple technical rule — not financial advice, and not a substitute for your own research.

Data via Twelve Data. Built with a 50-day SMA crossover rule.
